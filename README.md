# MAISON JUMANMODE

Fashion website built with React, Vite, Tailwind CSS, and Framer Motion.

## Development

Install Node.js 22, run npm ci, then npm run dev. Build with npm run build.

## Hosting

GitHub Pages deploys automatically from main using .github/workflows/pages.yml. The site uses relative asset paths and hash navigation so page links and refreshes work on GitHub Pages, including a future custom domain.

Website: https://oussamakhaba1999-svg.github.io/maison-jumanmode/

## Custom domain later

Add the purchased domain under Settings > Pages > Custom domain, configure the DNS records recommended by GitHub, and enable HTTPS after the certificate is ready. No domain is currently configured.

## Current limitations

The contact form simulates submission and does not send messages. The checkout is a front-end demonstration; it does not process payments or place orders. Connect real services before using these features with customers. Social links and contact number are from the supplied website; verify ownership before customer use.

## Assets

The homepage uses the supplied Singer sewing-machine portrait. Product images and remaining website code were imported from the provided Jumande.zip.

## Collections

Handmade Bags is at /#/shop and Bridal Dresses at /#/bridal. The bridal collection includes the Celestine Royal Gown, purchase/rental WhatsApp enquiries, and the supplied fitting-service copy. Original gown photographs were not included in the uploaded files; the atelier portrait is used with an accurate caption until original dress images are supplied.
