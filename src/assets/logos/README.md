### 2) Full Logo (JM + diamond + JUMANMODE wordmark)

### 3) Icon Logo (social profile)

- jumanmode-icon-black.svg

## Color specs
- Gold: #C9A96E
- Black: #000000
- White: #FFFFFF

## Notes
- All SVGs are transparent background by default.
- SVG is resolution-independent (high resolution / print-ready).
- For PNG export (e.g. 2048x2048), open in Figma/Illustrator and export with transparent background.
